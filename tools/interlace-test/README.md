# interlacetest — R20=$19 フィールド交替目視確認ディスク

MPX68K の R20=$19（HF=1/VRES=2）と偶奇フィールドの weave を確認する、
Human68k 不要のセルフブート XDF です。IPLROM の IOCS だけを使い、DOSや
著作物をディスクへ収録していません。

## 期待される表示

画面は縦に4つの色帯へ分かれます。各帯では次のように表示されます。

- 偶数フィールド由来の行: 左半分だけ着色
- 奇数フィールド由来の行: 右半分だけ別の色で着色

正しい場合、**4つの帯がすべて表示され、左右両側に色が見えます**。細い
走査線は表示倍率や補間によって混色して見えることがありますが、左右と4帯が
欠けていなければ両フィールドが weave されています。

異常の判別:

- 左右どちらか一方が黒い: 一方のフィールドしか更新されていない
- 上側の1帯しか出ない、または高さが大幅に小さい: 旧来の R20=$19
  double-read 解釈が残っている
- モード切替直後の黒い片側が次のフィールドでも埋まらない: parity が交替していない
- 帯の境界や左右が周期的に消える: weave バッファまたは dirty 行の保持に問題がある

## 使い方

`interlacetest.xdf` を FDD0 に挿入して起動します。HDDを外すか、ブート順を
FD優先にしてください。通常どおり IPLROM/CGROM は必要です。

## ビルド

```bash
PREFIX=m68k-elf- ./build.sh
```

GNU binutils for m68k が必要です。生成物は 77シリンダ×2面×8セクタ×1KB の
生2HDイメージで、先頭1KBだけにブートコードが入ります。

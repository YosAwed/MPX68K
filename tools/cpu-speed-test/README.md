# cpuspeedtest — CPU 実効クロック計測ディスク

1 フィールド(V-DISP の立ち上がりから次の立ち上がりまで)に 30 サイクルの
ループが何回回るかを数え、フィールドあたりの CPU サイクル数と、そこから
求めた実効クロックを表示し続けます。計測中は割り込みを禁止しています。
Human68k 不要のセルフブート XDF で、IPLROM の IOCS だけを使います。

## 期待値(CRTMOD 16 = 31kHz、約 55.46Hz)

| Clock メニュー | cycles/field | 表示 MHz |
|---|---|---|
| 1 MHz | 約 18,031 | 1.0 |
| 10 MHz | 約 180,310 | 10.0 |
| 16 MHz | 約 300,517 | 16.6(実機 XVI の 16.67MHz) |
| 24 MHz | 約 432,744 | 24.0 |
| 50 MHz | 約 901,550 | 50.0 |

誤差はおおむね 1% 以内です。
修正前の MPX68K では設定値の約 5 倍(10MHz 設定で約 50MHz)が表示されます。

Turbo / No-Wait はフィールドの進む速さだけを変えるので、cycles/field は
変わらず、表示の更新が速くなるのが正しい動作です。

## 使い方 / ビルド

`cpuspeedtest.xdf` を FDD0 に入れて起動します。ビルドは `./build.sh`
(Homebrew の elf2x68k なら `PREFIX=m68k-xelf- ./build.sh`)。
